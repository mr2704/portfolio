# Manas Raj — Ather Portfolio Starter

A responsive, static HTML/CSS/JavaScript portfolio designed for a fast, free GitHub Pages deployment. No build tools or package installation required.

## Before you submit — important checklist

1. **Verify every project description.** Replace generic descriptions with your actual role, implementation details, results, and exact repository/demo links.
2. **Add real creative work.** Put your images in `assets/photos/` using these exact names:
   - `photo-1.jpg`
   - `photo-2.jpg`
   - `photo-3.jpg`
   - `photo-4.jpg`
   The placeholders automatically disappear when images load.
3. **Add your resume.** Save a shareable PDF as `assets/resume.pdf`. The resume button points there.
4. **Add verified certificates/awards.** Edit the “Milestones” section in `index.html`; remove items you cannot verify.
5. **Confirm academic details and club role/dates.** The current page uses details previously shared by you, but you should compare them with your latest records.
6. **Replace the generic GitHub profile buttons** with exact repository or demo URLs once confirmed.
7. **Test all links and the mobile layout** before sending the portfolio URL to the recruiter.

## Run locally

Open `index.html` directly in your browser. For a local server, you can use VS Code Live Server or run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish free with GitHub Pages

1. Create a **public** repository named `mr2704.github.io` on GitHub (if available).
2. Upload the contents of this folder to the repository root. Make sure `index.html` is at the root, not buried in a nested folder.
3. In the repository, open **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for deployment and open `https://mr2704.github.io`.
6. Test the public site in an incognito/private window. GitHub Pages publishing can take a few minutes.

A GitHub Pages site hosted from a public repository is publicly accessible. Do not upload private keys, personal IDs, confidential information, or anything you do not want public.
